3. Prototipe Alat

4. Interface Website

6. Observasi lapangan
Kegiatan dilakukan sebelum perancangan alat maupun web bertujuan agar mengetahui kebutuhan yang diperlukan
Projek_2_Smart_Home.app

Smart Home Mini System Berbasis Raspberry Pi

SmartHome berbasis Raspberry Pi yang dirancang untuk efisiensi energi dan keamanan otomatis. Mengintegrasikan pemrosesan logika Python dengan antarmuka berbasis web.

1. Rangkaian Hardware
Integrasi papan penguji dengan modul relay, lampu indikator, dan komponen elektronik ke GPIO Raspberry Pi.
2. Pengujian Alat
Pengujian kontrol saklar dengan antarmuka berbasis website.
3. Web Interface
Tampilan antarmuka kontrol berbasis web (ON/OFF) yang responsif dari smartphone.
4. Otomatisasi & Log
Fitur otomatisasi daya lampu berdasarkan instruksi jadwal dan pencatatan riwayat penggunaan daya.
PROJEK_3_BRAIN_TUMOR_DETECTION.APP

Sistem Deteksi & Klasifikasi Tumor Otak Berbasis Deep Learning (CNN)

Aplikasi pengolahan citra medis otomatis berbasis Convolutional Neural Network (CNN) untuk membantu mendeteksi serta mengklasifikasikan keberadaan tumor otak dari hasil pemindaian MRI & CT Scan secara presisi.

1. Deteksi Positif Tumor
Pengujian sistem pada citra MRI yang teridentifikasi indikasi tumor ("Ada Citra Tumor").
2. Deteksi Negatif Tumor
Pengujian sistem pada citra MRI kondisi normal ("Tidak Ada Tumor").
3. Struktur Dataset AI
Pengorganisasian data latih (training) dan data uji (testing) untuk klasifikasi tumor.
4. Publikasi Jurnal Ilmiah
Dokumentasi & publikasi riset ilmiah mengenai implementasi algoritma CNN pada pemindaian MRI/CT Scan.
